# La Roca Gym — Demo

Prototipo navegable del sistema de gestión para La Roca Gym.

## Cómo probarlo
Abrir `index.html` en un navegador.

Usuario demo:
- Usuario: `admin`
- Contraseña: `demo`

## Publicarlo en GitHub Pages
1. Crear un repositorio, por ejemplo `la-roca-gym`.
2. Subir `index.html`.
3. En GitHub: Settings → Pages → Deploy from a branch.
4. Seleccionar la rama principal y la carpeta `/root`.
5. GitHub generará la URL pública.

## Importante
Esta es una demo frontend. Los datos son ficticios y se pierden al recargar.
La siguiente etapa puede incorporar Flask/Python + SQLite para convertirla en el sistema local real.
